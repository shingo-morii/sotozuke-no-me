# 入力を送る範囲

README の「入力を送る範囲」のくわしい説明。

遊ぶときの本体（`sotozuke`）がゲームへ入力を送るのは、利用者がゲームの設定の対応表（`input`）にあるキーを押した直後だけ。1回押して1つの動きだけで、送るのはマウスの移動、押し、ホイールのどれか。キーボードの入力は送らない。本体が自分から文を進めたり、選んだりしない。対応表が空のゲームでは何も送らない。

キーで動かないゲームでも、全盲の人が自分の手で操作できるようにするための決まり（2026-11-06 に守井が改めた。前は「本体はゲームにキーを送らない」）。

送る処理は `sotozuke/sender.py` の1か所にまとめてある。そこを呼ぶのは判断の中心が利用者のキーを受けたときだけで、そのことと、対応表が空なら何も送らないことは、テストで機械で確かめている。本体はキーを読むだけで、ゲームにキーが届くのは止めない。なので、対応表に書くのは、その画面でゲームが何もしないキーにする。それを確かめるのは取り込みの仕事。

探索の道具（`ingest`）と、手元の通しの試験の道具は、調べるためにキーとマウスを送る。
