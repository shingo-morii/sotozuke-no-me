# ゲームごとの設定

`add-game` のスキルが作る JSON をここに置く。権利の確かなゲームの設定だけをコミットする。権利の無いゲームの設定と見本の画面は `.local\` に置く。

主な項目は次のとおり。

- `size`：この設定が対応する画面の大きさ。ほかの大きさでは読まず、声で知らせる
- `voice_rule`：声の見分け方。`tag` は札で見る、`audio` は音で見る、`all` は全部読む
- `text`：本文の帯の位置と、字が止まったと見なす時間
- `tag`：名前の札の見分け方
- `scene`：場面の切り替わりを見る範囲
- `screens`：画面の種類の一覧。案内の字の形を見本と比べる
- `choice`：選択肢の範囲と、項目の数ごとの行の位置
- `keys`：次へ進むキーとカーソルのキー。入力を見るためだけに使う
